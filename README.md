# Pleasant Tours

Pleasant Tours is a tourism website designed to showcase beautiful destinations and help visitors explore different travel attractions. The website features beaches, forts and palaces, and hill stations through a simple and user-friendly interface.

## Features

- **Home Page:** An introduction to the Pleasant Tours website.
- **Beach Tours:** Explore beach destinations.
- **Forts & Palaces:** Discover historical forts and palaces.
- **Hill Stations:** Explore scenic hill stations.
- **Contact Page:** A dedicated page for contact information.
- **Image Assets:** Visual content to support the travel experience.

## Technologies Used

- HTML5
- CSS3
- Images and other website assets

## Website Pages

- `index.html` — Home page
- `beach_tours.html` — Beach tours
- `forts_palaces.html` — Forts and palaces
- `hill_stations.html` — Hill stations
- `contact.html` — Contact page

## Live Website

Visit the live website: https://usmankhan-nk.github.io/pleasant-tours/

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder on your computer.
3. Open `index.html` in your web browser.

## Project Purpose

This project was created to practise front-end web development and present travel destinations through a simple tourism website.
